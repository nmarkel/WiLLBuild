## Global Constraints (apply to every task in every sub-plan)

- All catalog knowledge lives in `public/catalog.json` — no hardcoded part lists, offsets, or compatibility logic in components or in the geometry kit.
- The config JSON shape (`PoleConfig`) is sacred: `{configId, pole, baseCover, arm, fixture, finish, rev}`.
- Compatibility = socket matching only; rules live in catalog socket data, not component code.
- Determinism: same config → geometrically identical output; config hash in every filename.
- Labeling: every generated file carries *"Concept starter model — not final engineered or manufacturing-released design"* + config ID (STEP header, DXF/DWG title block, PDF footer, IFC property, zip README).
- Brand: gunmetal `#42413D`, yellow `#FFCF2E` (CTAs/selected only, gunmetal text on yellow), silver `#E6E7E8`; **no blue anywhere**; Roboto/Open Sans.
- Units: 1 unit = 1 m in the viewer; CAD outputs in mm.
- Frontend: no localStorage for config; config lives in state + URL (leads.ts exception stands).
- TDD where a test can exist; commit after each task on branch `Dev`; run `npm run test && npm run lint && npm run build` (frontend) or `pytest` (service) before each commit.

## Frozen cross-plan contract — geometry-service HTTP API

Frontend (plan 03) and service (plan 02) are built against this, independently:

```
POST http://localhost:8000/generate
Content-Type: application/json
{
  "config": { "configId": "...", "pole": "alum-pole-20", "baseCover": "bc-fluted",
              "arm": "sh1-shepherds-hook", "fixture": "gvx-pendant",
              "finish": "matte-black", "rev": 3 },
  "formats": ["step", "dxf", "dwg", "ifc", "pdf", "bundle"],
  "renderPng": "<base64 PNG or null>"   // hero render for pdf/bundle
}
→ 200 {
  "configHash": "1a2b3c4d",
  "files": [ { "format": "step", "filename": "WiLL_1a2b3c4d_20ft-GVX.step",
               "url": "/files/WiLL_1a2b3c4d_20ft-GVX.step", "sizeBytes": 123456 } ],
  "warnings": []                         // e.g. "DWG skipped: ODA converter not installed"
}
→ 422 {"detail": "..."} on invalid config (unknown part id, incompatible combo)
GET /files/{filename} → the file
GET /health → {"status":"ok","adapters":{"step":true,"dxf":true,"dwg":false,"ifc":true,"pdf":true,"bundle":true}}
```

Frontend env var: `VITE_GEOMETRY_URL` (default `http://localhost:8000`).
